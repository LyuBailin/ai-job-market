# 数据更新工作流

## 监测目标

**国内市场为主**（中国 AI 就业市场），**海外仅记影响国内市场的事件**。

## 监测频次

- **每日**：快速扫描 RSS / 新闻聚合
- **每周**：深度核查是否需要更新
- **每月**：月末做一次完整数据校对
- **事件驱动**：重大事件发生时（融资过亿、监管文件发布、新模型发布等）当日更新

## 筛选规则

事件符合**任一**才入库：

1. **同比变化** ≥ 10%（薪资、岗位数、增速）
2. **政策文件** 发布（国家或重点城市）
3. **新模型** 发布（国内外头部公司）
4. **大额融资**（单轮 ≥ 1亿美元 或 公司估值变化显著）
5. **IPO 重大进展**（聆讯、挂牌）
6. **数据备案** 大幅增加

## 入库流程

```
1. 检索 → 找到原始报告/数据
2. 核对数据点（与 schema 字段匹配）
3. 在 data/*.json 追加数据点（append-only，不删不改历史）
4. 更新 meta.last_updated
5. 在 README.md 的 Changelog 记录本次更新
6. git commit
```

## 重要原则

- **append-only**：永远只追加，不覆盖历史
- **来源可追溯**：每条数据带 URL
- **置信度标注**：A/B/C/D 级
- **多源交叉**：关键数据至少 2 个独立来源
- **冲突说明**：来源冲突时记录所有数据 + 不强行收敛
