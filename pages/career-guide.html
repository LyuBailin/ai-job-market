稳健路径

3 年后的某一天

沉浸式预览三条路径下，3 年后你可能过的生活。

场景 1 · 稳健路径
3 年后，AI 应用开发工程师的一天

早上 9 点，你打开电脑，Cursor 已经在草稿区列出了昨天代码 review 留下的 3 个待修复点。10 分钟搞定，省下了一杯咖啡的时间。

10 点，团队 standup。PM 提了一个新需求：用 RAG + 私有知识库做一个内部"问数助手"。你心里已经在拆解：query 改写、向量库选型、Agent 多步推理、效果评估。3 年前你还在纠结"该不该转 AI"，现在你已经是团队最懂"AI 应用落地"的那个人。

下午，你在 GitHub 维护一个 200 star 的开源项目。一家猎头找过来，给了一个 35K×16 薪的高级岗 offer——不是大厂，但做的事情你喜欢。你决定再看看。

晚上回家，你在看《数学之美》。3 年前你以为自己只是个"调包侠"，现在你开始读懂 Transformer 的 attention 机制了。不是变聪明了，是积累到了那个量变到质变的临界点。

场景 2 · 突破路径
3 年后，大模型算法工程师的一天

早上 9 点半，你端着咖啡走进工位。昨晚的 ablation 实验跑完了，loss 曲线在 70B token 之后终于开始收敛。你打开日志，发现是数据清洗阶段的 bug。

10 点，跟组里 2 个博士同步：今天要做 RLHF 第二阶段的 reward model 调优。你是这条 pipeline 的 owner——3 年前你还在调开源模型的 LoRA，现在你负责的核心模块是公司基座模型的关键拼图。

下午 2 点，paper deadline。你和导师讨论了第 4 节的实验设计——这是你第三篇一作，方向是 Agent 的多轮 tool-use 评估。投的目标是 NeurIPS。

晚上 9 点，你和团队一起去庆功：今年发的模型在某个 benchmark 上首次超过了 GPT-4o。HR 给你推了一个"技术专家"的晋升通道，年包大概在 80-120 万之间。你没立刻答应，先回家想了一晚。

场景 3 · 探索路径
3 年后，AI Agent 工程师的一天

早上 8 点，你在家办公。你是一家具身智能创业公司的 #8 员工，负责 AgentOS 智能座舱的多模态决策模块。窗外是上海张江的早晨，团队分布在 5 个城市，靠 GitHub + 飞书协作。

10 点，跟硬件团队对齐：新一代传感器延迟降到 8ms，这意味着你的模型可以从 30Hz 提升到 60Hz。你开始重写 inference 流程。

下午，一个车企的客户来访。他们看了 demo 之后说"想预装 10 万台"。你心里算了一下：10 万台 × 50 元/台的 API 调用，毛利可观。你的期权终于开始值钱了。

晚上 8 点，你在写一篇博客："Agent 在垂直场景的 3 个反直觉经验"。3 年前你押注 Agent 的时候，市场还不成熟，今天你已经是某个细分方向的"早期玩家"。猎头找你开价 60 万年薪+期权，你没回应——你在等公司上市。

行动建议（基于数据）

如果你在读 / 应届生

选突破路径的概率最高（顶尖公司校招起薪 40-55 万）。

  • 基础课：高数/线代/概率 → ML/DL → Transformer
  • 实习：争取大厂或独角兽的算法实习
  • 论文：哪怕是 workshop 或 arXiv 预印本
  • 竞赛：Kaggle / 阿里天池 / 百度之星
如果你是 1-3 年经验的程序员

选稳健路径最稳（成功率最高，3 年后 15-30K/月）。

  • 主线：把现有工程能力 + LLM API 应用结合
  • 学习：LangChain / LlamaIndex / RAG 实战
  • 作品：1-2 个可演示的 AI 应用
  • 关注：业务理解，比算法更稀缺
如果你是 3-5 年经验 / 想转型

选探索路径（Agent / 具身智能）的窗口期最好。

  • 押注：Agent 框架（LangGraph / AutoGen）或具身
  • 选公司：选早期公司（员工 < 200）期权收益最大
  • 补短板：强化学习 + 机器人基础
  • Networking：AI 人才的 33.74% 好友通过率是普通人的 1.5 倍
